# 《颁什么奖》有志少年奖 · 独立HTML项目

## 独立运行

解压完整项目文件夹，使用现代Edge或Chrome直接打开[index.html](<index.html>)。可以把整个文件夹复制到其他机器或任意目录；不需要保留原工作区，不需要联网，不需要Node、Python、包管理器、AI、密钥或本地服务器。请勿只复制HTML单个文件。

文件夹包含运行所需的HTML、JavaScript、CSS、固定人物数据、14张PNG原画和思源黑体Regular字体。无CDN、远程字体和外部脚本，无上级目录引用。

图片从当前assets_png原样复制，未改色、未滤镜、未处理透明通道、未添加红色效果。manifest.json记录素材及运行文件的SHA-256值，便于核对。

1920×1080设计，窗口变化时等比缩放。界面、对白、报名表使用随包附带的思源黑体Regular，不必安装字体；公文使用系统宋体，若机器没有宋体则回退到系统serif，仍可运行但公文外观可能略有不同。未擅自打包Windows商业宋体字体。

## 操作

1. 第一幕：群聊回复“收到”，会议讨论结束后直接收表，不再投票或确认签发。
2. 第二幕：4张姓名/院系卡片可拖动，桌面左右2:1。拖入右侧入围区即入围，拖回左侧取消，以松手时卡片中心判定。恰好3人时可提交。双击展开A4表格，再次双击收回原位置；支持翻面、Esc和按钮收回。“整理桌面”保持名单。
3. 第三幕：每位入围者一位委员提问一次，回答后结束。裁定1位获奖者。
4. 第四幕：亲手递出证书，结束。本版不含余波、第五幕和终章。

页脚“名称设置”可修改玩家称呼和学校名，默认吴主任/本校。

进度保存在当前浏览器的本地存储中，不在项目文件夹里。复制项目不包含原机器的存档；不同浏览器、移动文件夹或隐私设置可能使存档不互通。浏览器禁止本地存储时仍能游玩，但刷新后无法续玩。“重新开始”重置本轮及名称配置。

## 已知占位

答辩和颁奖背景尚缺；whole_demogirl暂为通用候选人占位立绘，不改变候选人身份。委员会原全身素材通过布局裁为上半身，不修改图片本身。

## 结构

- [index.html](<index.html>)：入口。
- [app.js](<app.js>)：四幕状态机与交互。
- [style.css](<style.css>)：布局、字体及VI。
- [data.js](<data.js>)：4人固定报名材料与问答。
- assets/people：13张人物原画。
- assets/places：会议室原画。
- assets/fonts：思源黑体Regular。
- manifest.json：文件校验清单。

此项目是可编辑源文件，不是安装包。后续AI接入可另加内容提供层，本版本无任何AI请求。
